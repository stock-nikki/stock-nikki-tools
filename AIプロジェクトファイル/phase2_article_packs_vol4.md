# パックJ：投資イベントカレンダー記事

## 役割と価値

- **役割**：レーンC（更新型）。検索と再訪問の両取りを狙う定期資産
- **SEO**：「経済指標カレンダー 2026年◯月」「FOMC 日程 2026」「メジャーSQ いつ」。月次で確実に検索需要が発生する
- **読者価値**：イベント一覧＋「S株DCA勢はどう構えるか」の一言（他サイトにない視点）
- **投資判断価値**：翌月の材料を先に整理する習慣＝週次報告の「来週の注目材料」の仕込みになる

## 追記欄は設けない（2026-07-04決定）

- 結果追記欄は**廃止**。イベント結果と持ち株への影響の振り返りは週次ポートフォリオ報告に一本化
- 記事内には「振り返りは週次報告で」の案内を入れる（内部リンク導線を兼ねる）
- 理由：追記約束が守れず信頼毀損リスクになったため（6〜7月版で実証済みｗ）

## 持ち株直撃度（このパックの核）

全イベントに、一般的な重要度★とは別に**「S株44銘柄への直撃度」**を付ける。
プロジェクトファイルの現在ポートフォリオを参照し、セクター構成と照合して判定する。

| マーク | 定義 | 例 |
|---|---|---|
| 🔴 直撃 | 保有銘柄のセクターに直接影響。要マーク | 日銀会合→銀行・不動産株／ドル円系イベント→輸出・自動車株／米テック決算→半導体連動株 |
| 🟡 間接 | 地合い・為替経由でじわっと効く | 米CPI・雇用統計・FOMC等のマクロ全般 |
| ⚪ 静観 | S株長期DCA勢は気にしなくてOK | 影響が限定的・短期筋向けの指標 |

- 🔴には**どの保有セクター/銘柄群に効くか理由を一言**添える（判断材料としてこれが本体）
- 🔴が下落方向に効いた場合は「買い場候補」の視点も一言（煽らない範囲で）

## 月次更新サイクル

- 毎月25日前後に翌月版を公開（「2026年8月版」）
- 旧版の冒頭に新版へのリンクを追記（旧版は消さない・SEA評価の引き継ぎ）
- タイトル・スラッグは`investment-event-calendar-2026-08`形式で統一

## 見出し構成テンプレ

```
投資イベントカレンダー2026年◯月｜FOMC・日銀・雇用統計・決算まとめ
├ 挿絵①アイキャッチ（コメントで指示）
├ 導入＋重要度・直撃度の見方（凡例表）
├ クロちゃん的・今月の注目イベントTOP3（直撃度＋構え方一言）
├ 挿絵②
├ 月間カレンダー：海外イベント表（重要度★＋直撃度🔴🟡⚪＋参照元リンク）
├ 月間カレンダー：日本の経済指標表（同上）
├ 保有銘柄の決算予定（44銘柄該当分）
├ 挿絵③

```

※挿絵は3〜5箇所、生成用の描写コメント（<!-- 🎨 挿絵◯ -->形式）を本文に埋め込む（チャッピー生成用）。

## 依頼プロンプト（これだけでOK）

```
イベントカレンダー記事お願いします。
【期間】YYYY/MM/DD 〜 YYYY/MM/DD
```

## クロちゃんの自動実行レシピ（プロンプト2行の裏側）

1. **web検索で公式ソースを直接確認**：FRB（FOMC日程）・日銀（会合/短観/公表予定）・BLS（雇用統計/CPI/PPI）・BEA（GDP/PCE）・ECB・BOE・ISM・米Census・総務省統計局・JPX（SQ）
2. 日程は「確定/予定」を明記。日本時間に換算（深夜発表は「寝てる間に動く」注記）
3. プロジェクトのポートフォリオを参照し、全イベントに**持ち株直撃度🔴🟡⚪＋理由**を付与
4. 保有銘柄の決算予定を期間内分リストアップ（わかる範囲・要確認表記）
5. 構成は前回版（6〜7月版v2）踏襲、**追記欄なし**、挿絵コメント埋め込み、メタ情報ブロック付き
6. 定型更新のため構成案不要・即作業。ただし公式ソースで日程が確認できなかったものは「未確認」と正直に書く

## 追加チェック項目（カレンダー専用）

- [ ] 日程に「確定/予定」の区別がある（日銀・FOMC日程は変更があり得る）
- [ ] 全イベントに持ち株直撃度が付き、🔴には理由が一言添えてある
- [ ] 追記欄・追記の約束文言が**入っていない**
- [ ] 「振り返りは週次報告で」の案内がある
- [ ] 前月版の冒頭に新版リンクを追記した（新版公開とセット）
- [ ] スラッグが`investment-event-calendar-YYYY-MM`形式
- [ ] 挿絵コメントが3〜5箇所埋め込まれている

**⚠️ カテゴリ確認事項**：実サイトには「イベントカレンダー」カテゴリが存在するが、プロジェクトルールのカテゴリ一覧8個には含まれていない。①ルール側に追記する ②投資基礎知識に統合する、のどちらかを佐藤が決めること（スラッグ日本語問題と合わせて要整理）。

# パックK：自己破産からの再起ログ

## 役割と価値

- **役割**：レーンB。このブログの魂であり、競合ゼロ地帯。**書ける時に書く枠（ノルマにしない）**
- **SEO**：ボリューム小・競合ほぼゼロ・CVR（ファン化率）最強。「自己破産 後 投資」「自己破産 免責後 証券口座」「引揚同意書とは」「自己破産 持株会」
- **読者価値**：同じ状況の人にとって唯一の先行事例。E-E-A-Tの塊
- **投資判断価値**：二度と繰り返さないための自己文書化（信用取引をやらない理由の言語化）

## 語り方の憲法（Phase 1 §5より）

- **数字と手続きと日付で語る。感情と決意で語らない**（「頑張ります」より「◯月◯日に免責許可が出た」）
- 教訓の押し付けをしない。事実を置いて読者に判断させる
- 自虐ユーモアはOK、被害者ぶり・他責はNG

## 記事タイプ2系統

**系統1：手続き・実用型（SEO向け）**
「自己破産後に証券口座は作れるのか」「免責後の持株会はどうなる」「楽天銀行デビットカードという選択肢」等。同じ境遇の人の検索に正面から答える。
ネタ在庫：④楽天デビット ⑤SBIで投資再開 ⑫弁護士・手続き・生活再建系

**系統2：記録・エッセイ型（ファン向け）**
バイト生活・生活再建の実録。時系列の再起年表に積んでいく。
ネタ在庫：⑧平日EM・土日冷凍倉庫バイト ⑨バイトがクビになる話

## プライバシー・法務ガード（このパック最重要）

- [ ] 本名・勤務先・弁護士名・裁判所名・具体的な地名が出ていない（時期も必要ならぼかす）
- [ ] 法律アドバイスに見えない（「私の場合はこうだった」＋「個別の状況は専門家に相談を」を必ず入れる）
- [ ] 債権者・関係者が特定できる記述がない
- [ ] 金額・日付は出してOK（透明性の源泉）だが、出す範囲は佐藤が最終判断

## 見出し構成テンプレ（系統1：手続き・実用型）

```
（検索意図に応えるタイトル）｜自己破産経験者の実例
├ 結論：◯◯でした（即答）
├ 私の状況（時系列・前提条件）
├ 実際の手続き・起きたこと（日付と事実ベース)
├ つまずいた点・注意点
├ 同じ状況の人へ（＋専門家相談の案内）
└ 再起年表・関連記事リンク＋標準3リンク＋免責
```

## タイトル・メタ例

- 系統1：`自己破産しても株式投資は再開できる？免責後にSBI証券で口座を作った実例`
- 系統2：`平日は会社員、土日は冷凍倉庫バイト｜借金返済生活のリアルな1週間`
- メタディスク型：`自己破産からの再起を記録中の個人ブログ。◯◯を実体験・実際の日付ベースで書きます。同じ状況の方の参考になれば。`

# パックL：体験レビュー記事（収益化即効枠・追加）

## 役割と価値

- **役割**：Phase 1 §13の「体験ベース物販レビュー」の受け皿。楽天・もしも経由の収益化即効枠
- **SEO**：中。「商品名 レビュー」「商品名 ◯ヶ月使った」。実使用写真と正直なデメリットで薄いアフィ記事に勝つ
- **読者価値**：実際に金欠生活で厳選して買った物のレビュー＝「再起中の人の買い物」という独自文脈
- ネタ在庫：①モバイルバッテリー（アフィリンク待ち） ②ガジェット没収 ⑥NB996（4キロ通勤） ⑦筋トレ・ケアグッズ

## レビューの鉄則

- **実体験・実使用期間・実写真が三種の神器**。スペック転載だけの記事は書かない
- デメリット・買って後悔した点を必ず書く（正直さがこのブログの商品）
- 「再起生活のなかでなぜこれを買ったか」の文脈を入れる（投資ブログとの接続点。散財自虐もOKｗ）
- アフィリンクは「本文の流れで自然に1〜2箇所＋末尾に1箇所」まで。貼りすぎない

## 見出し構成テンプレ

```
商品名を◯ヶ月使ったガチレビュー｜（一言フック）
├ なぜ買ったか（再起生活の文脈・予算事情）
├ 良かった点（実使用エピソード＋写真挿入コメント）
├ イマイチな点・注意点（正直に）
├ こんな人に向く/向かない
├ 購入リンク（アフィ）
└ 関連レビュー記事リンク＋（投資に触れた場合のみ免責）
```

## 依頼プロンプト

```
体験レビュー記事お願いします。

【商品名】
【使用期間・使用シーン】
【良かった点・イマイチな点（箇条書きでOK）】
【アフィリンク先（楽天/もしも等）】

構成案を先に出してください。
```

## 追加チェック項目（レビュー専用）

- [ ] 実使用期間が明記されている
- [ ] デメリットが最低1つ書かれている
- [ ] 写真挿入コメントが本文にある
- [ ] アフィリンクが3箇所以内
- [ ] PR表記（ステマ規制対応）が入っている

**⚠️ カテゴリ確認事項**：現行8カテゴリにレビュー系の受け皿がない。既公開のガジェット系記事がどのカテゴリか確認の上、①「ブログ運営」に寄せる ②レビュー系カテゴリを正式新設する、を佐藤が判断（新設ならカテゴリ一覧ルールの更新とセットで）。
