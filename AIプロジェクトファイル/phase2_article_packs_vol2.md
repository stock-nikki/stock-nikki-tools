# パックE：個別銘柄分析記事

## 役割と価値

- **役割**：非保有銘柄（ウォッチリスト・気になる銘柄）を買う前に冷静に調査し、判断材料を公開ログ化する
- **SEO**：中〜高。「銘柄名 将来性」「銘柄名 やばい」「銘柄名 買い時」は検索需要があるが、**タイトルでは煽らない**（「調べてみた」「S株投資家目線で見る」の形）
- **読者価値**：機関レポートでもインフルエンサー推奨でもない、月1万円投資家の等身大の見方
- **投資判断価値**：「買わない理由」まで書くことで衝動買いの防波堤になる。監視条件が次の判断基準として残る

## 振り返り記事（パックC）との住み分け

| | パックC：振り返り | パックE：個別分析 |
|---|---|---|
| 対象 | 保有銘柄 | 非保有・ウォッチリスト銘柄 |
| 主目的 | 保有理由の言語化 | 買う前の調査・監視条件設定 |
| カテゴリ | 銘柄研究 | ウォッチリスト（S/A/B/C/D格付けと連動） |

## 見出し構成テンプレ

```
銘柄名（コード）を買う前に調べてみた｜S株投資家目線
├ なぜ気になったか（きっかけ・出会い）
├ 事業内容ざっくり（初心者向け）
├ 業績・財務の現在地（数値は要確認表記）
├ 配当・株主還元
├ 買いたい理由
├ 買わない・待つ理由（必ず書く）
├ 監視条件（何が起きたら買う/見送るか）
├ 佐藤の結論（買う/見送る/監視継続）
└ 標準3リンク＋免責
```

## タイトル・メタ例

- `SUBARU（7270）をS株で買う前に調べてみた｜円安メリットと関税リスクの綱引き`
- メタディスク型：`ウォッチリスト◯格付けの銘柄名を、月1万円S株投資家が買う前に調査。買いたい理由と買わない理由を両方残します。`

## クロちゃんへの依頼プロンプト

```
個別銘柄分析お願いします。カテゴリ：ウォッチリスト

【銘柄名・コード】
【気になったきっかけ】
【ウォッチリスト格付け（あれば）】
【株価・指標データ（スクショ or チャッピーTSV添付）】

197銘柄格付けとの整合、バトル対象銘柄との重複を確認してください。
構成案を先に出してください。
```

## 追加チェック項目（個別分析専用）

- [ ] 「買わない・待つ理由」セクションがある（買いたい理由だけの記事はNG）
- [ ] 監視条件が具体的（「◯◯円以下」「次の決算で◯◯なら」等）
- [ ] タイトルに「買うべき」「爆上げ」等の煽りがない
- [ ] 業種別ノームを踏まえている（機械的スクリーニング値の鵜呑み禁止・73円株事件の教訓）
- [ ] バトル対象銘柄の場合、バトル記事への内部リンクがある

カテゴリ：ウォッチリスト（watchlist）

# パックF：決算読み解き記事

## 役割と価値

- **役割**：保有銘柄の決算を読み、保有継続/監視強化の判断材料を残す。決算期の主力コンテンツ
- **SEO**：高いが賞味期限が短い。「銘柄名 決算 2026」は決算発表から数日が勝負。**スピード優先で短くてもいいから早く出す**
- **読者価値**：決算短信を「初心者が読めるレベル」に翻訳する
- **投資判断価値**：44銘柄の決算を毎回自分の言葉でまとめる＝決算を読む力の筋トレそのもの

## 運用設計

- 対象：保有44銘柄のうち、①大きく動いた銘柄 ②再会銘柄 ③バトル対象銘柄 を優先（全部やろうとしない）
- 決算期（5月・8月・11月・2月）は入口記事・振り返りを一時停止して決算枠に振り替え
- 決算まとめ記事（「今週の保有銘柄決算まとめ」）で複数銘柄を1本に束ねる形式もOK（1銘柄で書くほどでもない時）

## 見出し構成テンプレ

```
銘柄名（コード）2026年◯Q決算を読む｜保有S株投資家メモ
├ 決算3行まとめ（結論ファースト）
├ 数字の確認：売上・営業利益・純利益・進捗率（表、要確認表記）
├ 良かった点／気になった点
├ 配当・株主還元の変更有無
├ 株価の反応と市場の受け止め
├ 佐藤の判断（継続/監視強化/様子見）と次回決算で見るポイント
└ 標準3リンク＋免責
```

## タイトル・メタ例

- `安川電機（6506）2026年1Q決算を読む｜中国需要はどうだった？【保有中】`
- メタディスク型：`保有S株・銘柄名の◯Q決算を初心者目線で読み解き。進捗率◯%、配当◯円。継続保有の判断材料をメモします。`

## クロちゃんへの依頼プロンプト

```
決算読み解きお願いします。カテゴリ：銘柄研究

【銘柄名・コード】
【決算資料（短信スクショ or 数値貼り付け）※必須】
【株価の反応（当日の値動き）】
【佐藤の第一印象（1〜2行）】

決算数値は添付資料の実値のみ使用してください（web検索の数値で上書きしない）。
スピード優先のため構成案不要・即作業でOKです。
```

## 追加チェック項目（決算専用）

- [ ] 決算数値がすべて添付資料由来（AI検索値・記憶値を使っていない）
- [ ] 進捗率の計算が合っている（佐藤が電卓で検算）
- [ ] 決算発表から3日以内に公開できるか（無理なら週次報告内の言及に格下げ）
- [ ] 「売り/買い」ではなく「継続/監視/様子見」の語彙になっている
- [ ] 次回決算で見るポイントが書いてある（次回記事の下書きを兼ねる）

カテゴリ：銘柄研究（stock-research）

# パックG：配当・優待記事

## 役割と価値

- **役割**：レーンAの派生。「S株×配当」の実体験記事は検索と信頼の両取りができる
- **SEO**：高。「銘柄名 配当 いつ」「単元未満株 配当金 実際」「配当金 いくら 月1万円」等
- **読者価値**：**S株でも配当は株数比例でもらえる／優待は基本もらえない**という、公式が小さく書く事実を実体験で示せる
- **投資判断価値**：dividend_fetcher.py（--detail）の配当継続性指標を記事化＝自分の配当分析の精度向上

## 記事タイプ2系統

**系統1：実績報告型（ファン＋検索）**
「今月もらった配当金全部見せます」— 実際の入金スクショで語る。月次シリーズ化可能。

**系統2：銘柄・テーマ解説型（検索特化）**
「銘柄名の配当はいつ・いくら？」「S株で優待はもらえるのか問題」— レーンAの入口記事に近い設計。

## 見出し構成テンプレ（系統1：実績報告型）

```
2026年◯月の配当金◯円を全部見せる｜S株44銘柄の現実
├ 今月の配当合計と内訳（表・入金スクショ挿入コメント）
├ 初配当だった銘柄の話
├ 年間累計と「配当だけで◯◯が買える」換算（等身大ネタ）
├ 配当継続性で気になる銘柄（要確認表記）
└ 標準3リンク＋免責
```

## タイトル・メタ例

- 系統1：`2026年6月の配当金は487円でした｜S株44銘柄のリアルな現実ｗ`
- 系統2：`S株（単元未満株）でも配当金はもらえる？44銘柄保有者が入金画面を見せながら解説`
- メタディスク型：`月1万円のS株DCA、◯月の配当金は◯円。単元未満株の配当のリアルを入金実績ベースで公開します。`

## クロちゃんへの依頼プロンプト

```
配当記事お願いします。カテゴリ：損益報告（実績報告型）/ 投資基礎知識（解説型）

【系統】実績報告型 or 解説型
【配当データ（入金スクショ or dividend_fetcher出力）】
【今月の配当エピソード（初配当・増配など、あれば）】

構成案を先に出してください（実績報告型が定型化したら即作業に移行）。
```

## 追加チェック項目（配当・優待専用）

- [ ] 配当金額が入金スクショ実値と一致（fetcher出力のみで書いていない）
- [ ] 権利確定月・支払月の記述に「要確認」または一次ソース確認済み
- [ ] 「優待はS株では基本もらえない」を正直に書いている（優待に触れる場合）
- [ ] 利回りを未来の株価で語っていない（取得単価ベースか現在値ベースか明記）
- [ ] 小さい金額を恥じない書き方になっている（487円を堂々と出すのがこのブログ）

カテゴリ：実績報告型→損益報告（pnl-report）／解説型→投資基礎知識（investment-basics）

# 分析系の年間リズム

| 時期 | 主力 | 備考 |
|---|---|---|
| 決算期（5・8・11・2月） | 決算読み解き | 入口・振り返りは一時停止 |
| 通常期 | 個別分析（月1〜2本）＋配当実績報告（月1本） | ウォッチリスト格付け更新と連動 |
| 権利確定月の翌々月頃 | 配当実績報告が厚くなる | 3月決算銘柄の配当は6月頃入金 |

→ 第1弾の週間運用（水バトル・金週次＋週1本）の「週1本」枠に、時期に応じてはめ替える運用。総量は増やさない。
