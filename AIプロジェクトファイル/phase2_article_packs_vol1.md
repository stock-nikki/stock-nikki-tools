# パックA：週次ポートフォリオ更新記事

## 役割と価値

- **役割**：看板コンテンツ。毎週金曜固定の「週刊S株定点観測」
- **SEO**：狙わない（ファン用）。ただし週次タグ＋日付で指名検索・再訪の受け皿
- **読者価値**：月1万円DCAのリアルタイム経過観察。「続きが見たい」を作る
- **投資判断価値**：週単位の市況×自分のPFの反応を記録し、セクターローテーション認識を蓄積

## 制作フロー（既存ワークフロー＋拡張）

1. SBIスクショ＋東証33業種TSVをアップロード
2. チャート更新（stock-chart-all.html、6点バリデーション）
3. 市場ニュース検索（当週の主要材料）
4. 記事生成 ※ここまで既存フロー通り
5. **【拡張】固定セクション3つを本文に含める**（下記構成参照）

## 見出し構成テンプレ

```
【週次】（感情フックの一言）｜S株44銘柄 M/D
├ 今週のポートフォリオ（スクショ挿入コメント＋グラフHTML挿入コメント）
├ 今週の市況と自分のPFの反応
├ 動いた銘柄と理由（上昇・下落 各2〜3銘柄）
├ 📌固定1：投資額累計と目標進捗
├ 📌固定2：今週買った1銘柄とその理由
├ 📌固定3：10年前ポートフォリオとの再会銘柄（該当週のみ）
├ 来週の注目材料
└ 標準3リンク＋免責
```

## タイトル・メタ例

- タイトル型：`【週次】半導体に振り回された週｜S株44銘柄 7/4`
- メタディスク型：`月1万円のS株DCA、44銘柄の週次定点観測。今週は◯◯。投資額累計◯万円、含み損益◯円をリアルに公開。`

## クロちゃんへの依頼プロンプト（週次はこれだけでOK）

```

添付：SBIスクショ、東証33業種TSV、前回HTML

※定型更新のため構成案確認は不要（即作業）。
※戦略推奨はフレッシュに：レギュラー銘柄は月1回上限、当日市場イベント由来を最低1つ。

# パックB：S株入口記事（投資初心者向け解説）

## 役割と価値

- **役割**：検索流入の主戦場（レーンA）。月2本ペースで積む
- **SEO**：最重要。1記事1キーワードで検索意図に正面から答える
- **読者価値**：証券会社公式より本音、薄いアフィサイトより実体験
- **投資判断価値**：自分の運用ルールを言語化する副産物（教えることで整理される）

## キーワード在庫（Phase 1レーンAより・上から着手）

3. S株 手数料 SBI
4. 単元未満株 株主優待（もらえない話を正直に）
5. S株 NISA
6. 月1万円 株式投資（何銘柄買えるか実例）

- **必ず佐藤の実データ・実体験を入れる**（44銘柄・投資額・実際の配当金額・失敗談）。一般論だけの記事は書かない

# パックC：保有銘柄振り返り記事

## 役割と価値

- **役割**：研究ログの中核。44銘柄×1本でストック44本の連載資産
- **SEO**：中程度（「銘柄名 なぜ買った」「銘柄名 長期保有」で拾えることがある）。主目的は内部リンクの受け皿と判断記録
- **読者価値**：「月1万円の人はこの銘柄をこう見てる」という等身大の視点
- **投資判断価値**：最重要。保有理由の言語化＝握力。次の売買判断の一次資料になる

## 運用設計

- ペース：週1本（週次報告と別日）。約1年で44銘柄一巡
- 一巡後は「2周目」として更新（決算またぎで内容が変わるため資産が腐らない）
- シリーズ名を付ける：「S株44銘柄ぜんぶ振り返る」等（連載感で再訪を作る）

## 見出し構成テンプレ

```
【保有銘柄振り返り#N】銘柄名（コード）を持ち続ける理由
├ この銘柄を買った理由（購入時期・当時の判断）
├ 事業内容ざっくり（初心者向け1〜2段落）
├ 業績・配当の現在地（数値は要確認表記）
├ 10年前にも持ってた話（該当銘柄のみ・3度目の出会いナラティブ）
├ リスク・気になる点（正直に）
├ 継続保有の判断材料（何が崩れたら見直すか）
├ 佐藤の所感
└ 標準3リンク＋免責
```

## タイトル・メタ例

- `【保有銘柄振り返り#1】安川電機（6506）をS株で持ち続ける理由と不安なとこ`
- メタディスク型：`S株44銘柄を1つずつ振り返る連載#N。◯◯を保有する理由・リスク・見直し条件を月1万円投資家の目線で記録。`

## クロちゃんへの依頼プロンプト

```

# パックD：日次レポート（短報・任意運用）

## 役割と位置づけ

- **役割**：相場が動いた日・書きたい日に出す短報。**義務ではない**（連続更新を自分に課さない）
- **SEO**：狙わない。ファン向け＋自分の記録
- **週次との仕分け**：日次は「今日何が起きたか＋一言」まで。セクターローテーション等の深掘り分析は書かず週次に回す（日次で書くと週次のネタが枯れる）
- 目安：**本文600〜1,000字・作業10〜15分**で終える

## 見出し構成テンプレ（軽量版）

```
【日次報告】（感情フックの一言）｜S株44銘柄 M/D
├ 今日のポートフォリオ（スクショ挿入コメント＋グラフHTML挿入コメント）
├ 今日の一言（市況＋自分のPFの反応、2〜4段落まで）
├ 動いた銘柄メモ（上昇・下落 各1〜2銘柄、1行ずつ）
└ 標準3リンク＋免責
```

※「明日の注目」「戦略」セクションは付けない（週次と役割がかぶるため）。

## タイトル・メタ例

- タイトル型：`【日次報告】半導体総崩れでも底堅く踏ん張った｜S株44銘柄 7/2`（現行踏襲）
- メタディスク型：`月1万円S株DCA・44銘柄の今日の記録。◯◯な1日でした。含み損益◯円。`

## クロちゃんへの依頼プロンプト

```
日次短報お願いします。
添付：SBIスクショ（＋グラフ更新ありなら前回HTML）

【今日の一言（1〜2行）】
```

※定型更新のため構成案不要・即作業。
※グラフ更新なしの日はスクショのみでOK（グラフHTML挿入コメントは省略可）。

## 追加チェック項目（日次専用）

- [ ] スクショ挿入コメントが本文にある
- [ ] 本文が1,000字前後に収まっている（長くなったら週次に回す）
- [ ] 深掘り分析を書いていない（週次のネタ温存）
- [ ] 日次タグが付いている
- [ ] スラッグが英数字（日本語スラッグ事故の再発防止）

カテゴリ：損益報告（pnl-report）
