# 2段階スクリーニング・ワークフロー v1.1

> 2026-07-05 fable5策定（v1.1：候補100枠を新規専用化、買い増し比較をStage 2に移管）。
> 全銘柄TSV（japan-stock-radar.py 出力・約3,700銘柄）から長期保有候補を抽出し、
> 新規購入と保有銘柄の買い増しを同じ土俵で判断する運用。

---

## 設計思想

- **2層スコア**：品質判定（基礎スコア）は不変、時流（レジームボーナス±10）は買う順番にだけ効かせる
  → 同じTSVでも夏と冬で「順番」が変わる。ただし粗悪銘柄は地合いに関係なく通らない
- **役割分担**：チャッピー＝機械（計算・足切り・レジーム判定）／クロ＝アナリスト（業種ノーム・定性・買い増し比較）／佐藤＝最終判断
- **候補100枠は新規専用**：保有銘柄はStage 1の冒頭で除外する（放置すると優良な保有銘柄が枠の半分を占拠するため・実測済みｗ）
- **買い増し比較はStage 2**：クロが元の全銘柄TSVから保有銘柄の行をPython抽出し、同じスコア基準で計算して新規候補と直接比較する
- 機械スコア上位＝買いではない（73円株事件の教訓）。スコアは精査対象を選ぶ道具

## 運用フロー

```
japan-stock-radar.py 実行（全銘柄TSV生成）
  → Stage 1（チャッピー）：3,700 →（保有銘柄を除外）→ 新規候補100銘柄
  → Stage 2（クロ）：全銘柄TSVから保有分をPython抽出 → 新規30銘柄Tier分け＋買い増し比較＋配分所見
  → 佐藤：購入判断 → カルテ作成 → 購入
  → 記事化（物語型・カテゴリ：ウォッチリスト）
```

推奨頻度：月1回（月初）または四半期1回。毎週やるものではない（DCAは焦らないｗ）

# Step2: 基礎スコア（不変・100点満点）
- 連続増配(年)：10年以上=25 / 7〜9年=20 / 5〜6年=15 / 3〜4年=10 / 1〜2年=5 / 0=0
- 配当利回り(%)：3.5以上=10 / 3.0以上=8 / 2.5以上=5
- 配当性向(%)：30〜50=10 / 50超〜60=7 / 30未満=5 / 60超〜70=3
- 営業利益率(%)：15以上=15 / 10以上=10 / 5以上=5 / 5未満=2
- ROE(%)：12以上=10 / 8以上=7 / 5以上=3 / それ未満=0
- 売上成長率_YoY(%)：5以上=10 / 0以上=5 / マイナス=0
- 自己資本比率(%)：50以上=10 / 40以上=7 / 30以上=4（金融免除銘柄は一律4）
- FCF(百万円)：プラス=10 / マイナスまたは欠損=0

# Step3: 時流ボーナス（可変・-10〜+10点）
Step0の判定結果に応じて、該当33業種に加減点する。適用したルールを判定ログに明記する。

【金利】
- 利上げ局面：銀行業・保険業に+5 ／ 不動産業に-5
- 利下げ局面：不動産業・建設業に+5 ／ 銀行業に-3
【為替】
- 円安進行：輸送用機器・機械・電気機器に+5 ／ 小売業・食料品に-3
- 円高進行：小売業・食料品・空運業に+5 ／ 輸送用機器・機械に-3
【地合い】
- 軟調：食料品・医薬品・情報・通信業に+3（ディフェンシブ）、
  さらに⚠安値圏フラグ銘柄のうち基礎スコア60点以上のものに「🛒買い場候補」マークを付ける
- 強気：加点なし（過熱時に順張りしない）
【セクター騰落】
- 直近1ヶ月の下位3業種に+3（逆張りDCA視点）／上位3業種に-3（高値掴み回避）
※合計は-10〜+10でクリップする

# Step4: 罠フラグ付与（除外はしない。印を付けるだけ）
- ⚠高利回り：配当利回り5%超
- ⚠割高：PER 25超
- ⚠超割安：PER 5未満 または PBR 0.5未満
- ⚠減収：売上成長率_YoY -10%以下
- ⚠安値圏：株価が52週安値の1.05倍以下

# Step5: セクター分散と選出（不変）
総合スコア（基礎＋時流）降順で、33業種区分ごとに上位8銘柄まで。その上で全体上位100銘柄を選出。

# 出力形式
1. 判定ログ：Step0の4項目の確認結果と、適用した時流ボーナスルール一覧
2. 候補100銘柄TSV（ダウンロード可能な形で）。列は以下の順：
コード / 銘柄名 / 33業種区分 / 株価 / 配当利回り(%) / 連続増配(年) / 配当性向(%) /
営業利益率(%) / ROE(%) / 自己資本比率(%) / PER / PBR / 時価総額(億円) /
基礎スコア / 時流ボーナス / 総合スコア / 罠フラグ / 買い場マーク / 選定理由
3. 業種別の銘柄数分布と、フィルタ各段階の通過数（保有銘柄除外での減少数も報告）

選定理由は各銘柄1行、データにある数値のみ使用（創作・推測禁止）。

## Stage 2：クロちゃんの実行レシピ

依頼プロンプト（これだけでOK）：

```
スクリーニングStage 2お願いします。
添付：①チャッピーの候補100銘柄TSV ②元の全銘柄TSV ③判定ログ

【今月の予算（省略時1万円）】
【気になってる銘柄・所感（あれば）】
```

クロちゃんが自動でやること：

1. **保有銘柄の同基準スコア計算**：元の全銘柄TSVから保有銘柄の行をPythonで抽出し、
   Stage 1と同じ基礎スコア・時流ボーナス・罠フラグを計算（コード実行のためトークン消費は最小）
2. **レジーム判定の検証**：チャッピーのStep0判定をweb検索で答え合わせ（古い・誤りなら補正して明記）
3. **定性評価**：業種ノーム照合（商社の低PERは正常等）・ビジネスモデル・競争優位・罠フラグの個別検証
4. **照合**：現在ポートフォリオとのセクター重複／2014・2015年リスト（再会銘柄）／既存カルテの買い増し条件
5. **新規 vs 買い増しの直接比較**：セクターが重複する場合、「新規候補◯◯ vs 保有◯◯の買い増し」を
   スコア・取得単価との乖離・PF内ウェイトを添えて判定
6. **出力**：
   - 新規候補30銘柄：Tier1（カルテ作成候補10）／Tier2（監視10）／Tier3（条件待ち10）、優先順位＋理由付き
   - 買い増し推奨：保有銘柄から最大5銘柄、理由付き
   - **総合所見「今月は幅か、厚みか」**：PFの現状分散度を踏まえた予算配分の考え方（判断は佐藤）
7. Tier1銘柄は「カルテ作って」の一言でカルテ化に接続

## 記事化方針

- 型：**物語型**「約3,700銘柄から30銘柄を探す旅」（リスト羅列ではなく過程と判断を見せる）
- カテゴリ：ウォッチリスト（watchlist）
- 判定ログ（今月のレジーム）を名物コーナー化。月次シリーズなら毎回自然に内容が変わる
- 買い増し検討の結論は「私はこう配分する」の一人称で書く（推奨に見せない）＋免責必須
- 罠フラグで弾かれた高利回り株の話は読者価値が高い（「利回り6%に飛びつかない理由」）
