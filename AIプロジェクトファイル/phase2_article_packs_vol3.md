# パックH：クロvsチャッピー銘柄バトル運用パック

## 役割と価値

- **役割**：ファン化・SNS装置。ブログの「顔」となる連載企画。SEOは狙わない（指名検索用）
- **読者価値**：AI2体の予測が当たるか外れるかのエンタメ＋銘柄分析の副読本
- **投資判断価値**：AI予測の精度を実測記録する一次データが貯まる（→半年まとめ記事の素材）
- 必ず「エンタメ企画」宣言＋免責を維持（売買推奨に見せない生命線）

## バトル1ラウンドの構成（2記事＋更新2箇所）

| # | 成果物 | タイミング |
|---|---|---|
| 1 | 予測発表記事 | ラウンド開始時 |
| 2 | 結果発表記事 | 判定日 |
| 3 | 戦績一覧固定ページ（/battle-results/）更新 | 結果記事と同日 |
| 4 | サイドバーウィジェットHTML更新 | 結果記事と同日 |

**⚠️ 3点セット（#2〜#4）は同日必須。固定ページとサイドバーの成績矛盾は信頼を直撃する（Phase 1指摘事項）。**

## 予測発表記事：見出し構成テンプレ

```
【クロvsチャッピー】第N回予測発表｜◯◯セクター対決：銘柄A vs 銘柄B
├ 今回のルールとお題（セクター・判定日・判定基準）
├ チャッピーの選択と言い分（> 引用形式）
├ クロちゃんの選択と言い分（> 引用形式）
├ 両者の分析比較表（数値は要確認表記）
├ 佐藤の観戦コメント（どっちが勝ちそうかの野次馬視点）
├ 現在の通算成績＋判定日の予告
└ 戦績一覧・最新週次報告への内部リンク＋エンタメ宣言＋免責
```

## 結果発表記事：見出し構成テンプレ

```
【クロvsチャッピー】第N回結果発表｜勝者は◯◯！通算◯勝◯敗
├ 結果3行まとめ（勝者・騰落率・通算成績）
├ 判定：両銘柄の騰落率（スクショ実値、表）
├ 勝者のドヤ台詞／敗者の言い訳（> 引用形式・キャラ芸）
├ なぜこの結果になったか（市況・材料の振り返り）
├ 予測時の分析はどこが当たり/外れたか
├ 次回予告
└ 戦績一覧・最新週次報告への内部リンク＋エンタメ宣言＋免責
```

## 依頼プロンプト

```
バトル第N回【予測 or 結果】お願いします。

# 予測の場合
【お題セクター】【判定日・判定基準】
【チャッピーの選択銘柄と言い分（貼り付け）】
→ クロちゃんはこのセッション内で対抗銘柄を選んで言い分を書く

# 結果の場合
【両銘柄の判定日株価スクショ】※必須
→ 結果記事＋戦績固定ページ更新分＋サイドバーHTML更新分の3点を出力
```

※騰落率は**スクショ実値のみで計算**（API・検索値で判定しない）。
※結果依頼時は3点セットを1セッションで完結させる（更新漏れ防止）。

## アイキャッチ運用（バトル固有）

- キャラ設定固定：チャッピー＝妖狐（白・猫科）金髪・特攻服・さらしのヤンデレヤンキー／クロちゃん＝天狗（黒・犬科）清楚な制服のツンデレ優等生
- **結果発表のアイキャッチは「幼稚園児が書いた風」固定**（シリーズの様式美）
- 画像生成プロンプトは日本語・コードブロックでチャッピー用に出力

## 半年まとめ記事（バトルのSEO出口・年2回）

- タイトル型：`AIの株価予測は当たるのか？ChatGPT vs Claude 全N回ガチ対決の実測データ`
- 狙うKW：「AI 株価予測 当たる」「ChatGPT 株 予測」
- 内容：全ラウンドの騰落率一覧・勝率・当たった/外れた分析の傾向・「AIを投資に使う時の現実的な注意点」
- カテゴリ：クロvsチャッピー（ai-battle）。全バトル記事からここへ内部リンクを集約

## 追加チェック項目（バトル専用）

- [ ] 騰落率がスクショ実値ベース（判定計算を佐藤が検算）
- [ ] 3点セット（結果記事・固定ページ・サイドバー）の成績が一致している
- [ ] エンタメ宣言＋免責がある
- [ ] 対象銘柄が保有銘柄/ウォッチリストの場合、該当記事への内部リンクがある
- [ ] 結果アイキャッチが幼稚園児風になっている

カテゴリ：クロvsチャッピー（ai-battle）

# パックI：AI活用記事

## 役割と価値

- **役割**：「AI×投資の実践」という差別化の柱を記事化。ツール・ワークフロー・失敗談の3本立て
- **SEO**：中〜高。「ChatGPT 株 分析 プロンプト」「AI 銘柄分析 やり方」等。技術系読者の流入口
- **読者価値**：再現可能な手順＋実際に起きた失敗。AI万能論サイトとの決定的な差別化
- **投資判断価値**：自分のワークフローの棚卸し・改善が進む

## 記事タイプ3系統

**系統1：ツール公開型**
dividend_fetcher.py等の自作ツール解説。使い方・出力例・GitHubリンク。/utility-tools/固定ページからリンクを集約。

**系統2：ワークフロー公開型**
「週次更新をAI2体でどう回してるか」「197銘柄をAIで格付けした手順」等。プロンプト実物をコードブロックで公開（このブログの太っ腹芸）。

**系統3：AI失敗談型（このブログの名物枠）**
「たいかくりょう」事件のような、AIの間違い・幻覚を面白く＋教訓化。「AIを鵜呑みにするな」系は読者に刺さる実績あり。

## 見出し構成テンプレ（系統共通の骨格）

```
（やったこと/起きたことがわかるタイトル）
├ 何をしようとしたか（背景・動機）
├ 実際の手順 or 実際に起きたこと（プロンプト・出力はコードブロック/引用）
├ 結果どうだったか（スクショ・実データ）
├ ハマった点・AIが間違えた点（正直に）
├ 教訓：こう使うのが現実的
├ 再現したい人向けの手順まとめ（系統1・2のみ）
└ 標準3リンク＋免責（投資判断に触れる場合）
```

## タイトル・メタ例

- 系統1：`配当データを一括取得するPythonツールを作った｜約3,700銘柄対応・コード公開`
- 系統2：`ChatGPTとClaudeの2体体制で投資ブログを回す方法｜プロンプト全公開`
- 系統3：`Claudeが「貸株料＝たいかくりょう」と嘘をついた話｜AIを鵜呑みにしてはいけない実例`
- メタディスク型：`AI2体（ChatGPT・Claude）で投資分析を実践中の個人投資家が、◯◯の手順と失敗を実例で公開します。`

## 依頼プロンプト

```
AI活用記事お願いします。カテゴリ：ブログ運営 or 投資基礎知識（内容次第で確認）

【系統】ツール公開 / ワークフロー公開 / 失敗談
【題材】
【素材（コード・プロンプト・スクショ・事件の経緯）】

構成案を先に出してください。
```

## 追加チェック項目（AI活用専用）

- [ ] プロンプト・コードがコードブロックで囲まれている
- [ ] 公開するプロンプト/コードに個人情報・APIキー・本名が含まれていない
- [ ] AIの限界・失敗への言及がある（万能論になっていない）
- [ ] 銘柄名に言及する場合、売買推奨に見えない＋免責がある
- [ ] GitHubリンク・関連ツール記事への内部リンクがある（系統1）

カテゴリ：内容によりブログ運営（blog-management）または投資基礎知識（investment-basics）※迷ったら佐藤に確認
